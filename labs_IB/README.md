# Лабораторная работа №1

**«Разработка программы разграничения полномочий пользователей на основе парольной аутентификации»**

Автор: Kanteev Sergei, группа IDB-23-08
Вариант 10: пароль должен содержать латинские буквы, символы кириллицы и цифры.

Учётные записи хранятся не в файле, а в базе данных PostgreSQL (чистый JDBC, без ORM).
Интерфейс — Swing, формы сделаны в NetBeans GUI Builder (пары `*.java` + `*.form`).

## 1. Создание базы данных

Создать базу `lab1`:

```
psql -U postgres -c "CREATE DATABASE lab1;"
```

Таблицу программа создаёт сама при первом запуске, но её можно создать и вручную:

```
psql -U postgres -d lab1 -f sql/init.sql
```

Скрипт `sql/init.sql` создаёт таблицу `users` и добавляет учётную запись `ADMIN` с пустым паролем.

## 2. Настройка подключения

Параметры подключения лежат в `src/main/resources/db.properties`:

```
db.url=jdbc:postgresql://localhost:5432/lab1
db.user=postgres
db.password=postgres
```

Файл попадает внутрь jar при сборке, поэтому править его нужно до `mvn package`.
Если подключиться не удалось, программа покажет сообщение об ошибке и завершится.

## 3. Сборка и запуск

```
mvn clean package
java -jar target/lab1.jar
```

JDBC-драйвер PostgreSQL упакован в jar (maven-shade-plugin), отдельно его подкладывать не нужно.

## 3.1. Окружение через Nix (необязательно)

Если в системе нет JDK, Maven, NetBeans и PostgreSQL, всё нужное поднимается одной командой:

```
nix-shell develop.nix
```

Внутри оболочки доступны `netbeans`, `mvn`, `java`, а также `pg-start` (поднимает локальный
PostgreSQL в `./.pgdata` и создаёт базу `lab1`) и `pg-stop`.
NetBeans 30 требует Java 21+, поэтому в окружении стоит JDK 21, а проект компилируется под Java 17.

## 4. Открытие в NetBeans

File → Open Project… → выбрать папку `lab1` (Maven-проект определяется автоматически).
Окна открываются в режиме Design: `src/main/java/lab1/gui/*.java` → вкладка **Design**.
Запуск — Run → Run Project (главный класс `lab1.Main`).

## 5. Первый вход

Имя: `ADMIN`, пароль оставить пустым → программа потребует задать пароль
(окно «Установка пароля при первом входе», старый пароль не спрашивается,
новый пароль нужно ввести дважды). Отказ от установки пароля завершает программу.

Дальше администратор может добавлять пользователей («Пользователи» → «Добавить пользователя»)
и менять их флаги блокировки и ограничений («Пользователи» → «Список пользователей»).
Новый пользователь создаётся с пустым паролем и при первом входе тоже задаёт себе пароль.

Обычный пользователь может только сменить свой пароль и выйти,
меню «Пользователи» для него заблокировано.

## 6. Состав проекта

```
lab1/
├── pom.xml
├── README.md
├── sql/init.sql
└── src/main/
    ├── resources/db.properties
    └── java/lab1/
        ├── Main.java               запуск, создание таблицы и ADMIN
        ├── Db.java                 соединение с PostgreSQL
        ├── User.java               учётная запись
        ├── UserDao.java            SQL-запросы к таблице users
        ├── Session.java            текущий пользователь и режим
        ├── PasswordValidator.java  проверка пароля (вариант 10)
        └── gui/
            ├── LoginDialog          вход
            ├── MainFrame            главное окно (меню, панель, строка состояния)
            ├── ChangePasswordDialog смена / установка пароля
            ├── AddUserDialog        добавление пользователя
            ├── UsersDialog          список пользователей
            └── AboutDialog          о программе
```
